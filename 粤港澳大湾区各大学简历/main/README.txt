【二、怎么改内容】

1. 用文本编辑器打开 main.tex
   推荐 VS Code 或 Notepad++，不要用 Word（会破坏格式）。

2. 章节顺序：
   教育经历 → 技术能力 → 实习经历 → 项目与科研经历

3. 一条经历的标准写法：

   \ResumeItem{单位 | 岗位}[一句话项目名][起始—结束]
   {\zihao{5} 背景与任务，一句话说清问题和目标}
   \begin{itemize}
       \item \textbf{加粗小标题}：具体做法、数据、结果
   \end{itemize}

   注意：\ResumeItem 后面第一个 {} 是单位，第一个 [] 是岗位，
   第二个 [] 是时间，顺序别写反。

4. 换头像：直接把新图片命名成 touxiang.jpg 覆盖 assets\touxiang.jpg
   换校徽：同理替换 assets\xiaohui.png


【三、怎么编译成 PDF】

方式一（命令行，最稳）
  在项目文件夹里打开终端（地址栏输入 cmd 回车），执行两遍：

      xelatex main.tex
      xelatex main.tex

  如果提示"不是内部或外部命令"，用完整路径：

      "C:\Program Files\MiKTeX\miktex\bin\x64\xelatex.exe" main.tex

  为什么跑两遍：校徽 / 头像 / 牌坊 / 校训都是用 remember picture 叠加定位的，
  需要上一遍 .aux 里记录的位置信息；只跑一遍，装饰会错位或跑到别处。
  所以务必连着跑两遍，第二遍出来的 PDF 才是对的。

方式二（VS Code）
  安装 LaTeX Workshop 插件，打开 main.tex 后保存即自动编译。

方式三（Overleaf 在线）
  把整个文件夹打包上传，编译器必须选 XeLaTeX。


【四、注意事项】

1. 编译器必须是 XeLaTeX，不能用 pdfLaTeX —— 中文和字体依赖它。

2. 简历必须控制在一页。改完如果溢出成两页，优先删这些：
   重复的收尾句、没有数字的形容词句、别人也能写的通用描述。
   不要删量化成果（如 31.6% 降至 9%、节省约 20 万元）。

3. 图片路径写的是 assets/xxx。如果移动或重命名图片，
   必须同步改 main.tex 里对应的 \includegraphics（共 6 处：
   校徽、头像、牌坊、校训三张），否则编译报错。

4. main.aux / main.log / main.out / main.synctex.gz
   都是编译临时文件，每次编译重新生成，可以随时删掉。

5. 想调行距、边距、列表间距：在 resume.cls 里找
   \linespread{1.15} 和 \geometry{margin=1cm} 两处。
   改 cls 有风险，改前备份一份。

6. 右下角的牌坊（华工五山校区石牌坊）是装饰底纹。
   在 main.tex 里搜 "south east" 就能找到那一段，三个参数随便调：

     width=5cm, height=3.4cm   图案大小。
                    原图是 800×800 正方形，宽 > 高 就是横向拉长成纹样带。
                    想更宽就把 width 加大（别超 6.5cm，会爬上最后两行正文）。
     opacity=0.18   深浅（0 全透明，1 实色）
     inner sep=0.4cm   距页面右下角的距离

   不想要这个装饰，就把那段的三行前面各加一个 % 注释掉。

   注意：简历已排满整页，右下角没有空白，所以牌坊只能用低透明度做底纹。
   opacity 调到 0.3 以上，线条会明显压在文字上，慎调。

7. 页脚正中的校训「博学 · 慎思 · 笃行」（三张竖排双字图并排）。
   在 main.tex 里搜 "boxue" 就能找到那一段，四个参数随便调：

     height=1.35cm     字幅高度（三张图等比缩放，宽度自动）
     opacity=0.85      深浅（0 全透明，1 实色）
     yshift=0.02cm     距页面底边的距离
     \hspace{4cm}      两列之间的间距（出现两次）

   高度为什么不能再加：正文最后一行的底边距页底正好 1.37cm
   （实测 38.77pt），校训 height 一旦超过 1.37cm 就会压到正文。
   现在 1.35cm 卡在这条空隙里，一个字都不压正文。

   横向为什么不能再加：三张图在 height=1.35cm 下总宽仅 1.52cm，
   加上两边 \hspace{4cm} 后整块宽 9.52cm，居中后占 x 5.74cm ~ 15.26cm。
   右下角牌坊的左沿在 x 15.60cm，只剩 0.34cm 空隙 ——
   所以 \hspace 最大只能调到约 4.3cm，再大「笃行」就会压到牌坊上。
   左侧 x 4.82cm 处是正文末行的续行「的全链条研发能力。」，
   距校训左沿还有 0.9cm，不受影响。

   想更醒目就加深 opacity（0.85 → 1.0），但 height 和 \hspace 都别再往上加。

   不想要这个装饰，把这段的三行前面各加一个 % 注释掉即可。
